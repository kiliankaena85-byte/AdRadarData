# Verify Gate Skill (Регламент работы с Acceptance Gate)

Этот навык описывает обязательную процедуру запуска единого приемочного шлюза проекта AdRadar перед завершением любой задачи или передачей сессии.

## Регламент исполнения

### 1. Запуск приемочного шлюза
Запусти полную цепочку верификации через надзиратель Harness:
```powershell
.venv\Scripts\python.exe harness.py gate
```

### 2. Структура проверок шлюза
Шлюз последовательно прогоняет 5 фаз контроля:
1. **Gate 1 (Sync & AST Guard)**: синхронизация в `.venv`, компиляция байткода и сканирование на запрещенные `random`, `Faker`, `ProceduralCaseSimulator`.
2. **Gate 2 (Pytest Suite)**: автоматические тесты `legal_sheaf_verifier/tests`.
3. **Gate 3 (Doctor & Live Canaries)**: валидность бандла `champion_v2.bundle`, живой опрос РКН (`pd.rkn.gov.ru`) и ФНС (`bo.nalog.gov.ru`).
4. **Gate 4 (Semantic Business Oracles)**:
   - *Oracle A*: Ненулевая вилка штрафа (`fine_max_rub > 0`) при наличии нарушений `RED`.
   - *Oracle B*: Отсутствие сырых машинных слагов и kebab-case идентификаторов в человеческом тексте.
   - *Oracle C*: Корректный учет `/privacy-policy` и отсутствие ложного `missing-privacy-policy-link`, сквозная дедупликация.
   - *Oracle D*: Dogfooding 152-ФЗ — клиентский HTML отчет не имеет внешних CDN-зависимостей и проходит валидацию с 0 нарушений.
   - *Oracle E*: VC.ru API v2.8 отвечает 200 OK без 404 ошибок.

### 3. Действия при обнаружении ошибок (Fail-Loud)
- Если гейт вернул `Exit code 2`: внимательно прочитай текст ошибки конкретного Оракула.
- **Запрещено** ослаблять или отключать проверки Оракулов или модифицировать калибровочные файлы под тест. Исправлять необходимо исключительно исходный код ядра (`legal_sheaf_verifier/src/`).
- После исправления кода повтори запуск `python harness.py gate` до получения строки:
  `HARNESS_GATE_STATUS: PASSED` (`Exit code: 0`).

### 4. Синхронизация состояния
- После успешного прохождения шлюза обнови статус в `MEMORY.md` (раздел `Active Queue`).
- Сформируй протокол проверки инструментами с сырым выводом команд.
