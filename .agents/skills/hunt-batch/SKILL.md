# Hunt Batch Skill (Сбор и аудит лидов с VC.ru)

Этот навык регламентирует конвейер сбора свежих публикаций VC.ru, выделения рекламодателей, их обогащения через реестры РФ и фильтрации качественных B2B-лидов.

## Регламент исполнения

### 1. Подготовка и предварительная верификация
Перед запуском боевого сбора убедись, что среда синхронизирована:
```powershell
.venv\Scripts\python.exe harness.py sync
```

### 2. Запуск пакетного сбора VC.ru
Вызови CLI команду `hunt-vcru` с требуемым лимитом статей (по умолчанию 50):
```powershell
.venv\Scripts\adradar.exe hunt-vcru --limit 50 --output-dir C:\AdRadarData\reports\leads
```

### 3. Правила фильтрации и валидации компаний
При обработке найденных рекламодателей:
1. **Валидация ИНН по ФНС**: каждый ИНН обязан проходить 10- или 12-значную проверку контрольной суммы. Невалидные строки отбрасываются.
2. **Исключение иностранных КИО**: организации с ИНН, начинающимся на `9909...`, помечаются как иностранные структуры (КИО). Они исключаются из стандартного контура взыскания КоАП РФ.
3. **Отсев госсектора и некоммерческих структур**: фокус аудита — коммерческие компании (ООО / АО / ИП), ведущие реальную хозяйственную деятельность в РФ.
4. **Финансовый ценз (ГИР БО ФНС)**: выручка извлекается через `bo.nalog.gov.ru`. Приоритетные лиды — компании с выручкой от 10 млн до 800 млн руб. (МСП с финансовым ресурсом для устранения рисков).

### 4. Контроль качества отчетов
- Сформированные отчеты сохраняются строго в `C:\AdRadarData\reports\leads\`.
- Каждый отчет обязан содержать автономный `index.html` (без CDN) и персонализированный аутрич-черновик `outreach_draft.txt` с корректной вилкой КоАП.
