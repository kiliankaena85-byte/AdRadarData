# Verify AdRadar Skill (Регламент верификации движка)

Этот навык определяет обязательный регламент верификации изменений в пакете `legal_sheaf_verifier`, целостности бандла и соответствия КоАП РФ.

## Пошаговый чек-лист проверки (Verification Checklist)

### Шаг 1. Обязательная синхронизация исходников в `.venv`
Перед любым запуском CLI или внешних тестов синхронизируй измененные исходники из репозитория в установленный пакет виртуального окружения:
```powershell
Copy-Item -Path "legal_sheaf_verifier\src\legal_sheaf\*" -Destination ".venv\Lib\site-packages\legal_sheaf\" -Recurse -Force
```

### Шаг 2. Запуск полного набора автоматических тестов (Pytest)
Запусти тесты и убедись в отсутствии регрессий и падений (код возврата 0):
```powershell
.venv\Scripts\python -m pytest legal_sheaf_verifier\tests -v
```
Все тесты (12 правовых аксиом, эндпоинты, математика пучков, инварианты) обязаны завершаться со статусом `PASSED`.

### Шаг 3. Запуск системной диагностики с живыми канарейками (Zero-Mock Canaries)
Проверь доступность внешних государственных реестров и нейросетевого бандла:
```powershell
.venv\Scripts\adradar doctor --live-canaries
```
Критерии успеха:
- `Champion Bundle v2` SHA-256 валиден.
- Реестр операторов РКН (`pd.rkn.gov.ru`) подтверждает оператора (ИНН 6670408100).
- ГИР БО ФНС (`bo.nalog.gov.ru`) подтверждает выручку компании (ИНН 7704386120).
- Golden Canaries (статья и сайт) подтверждают точность калибровки бандла.

### Шаг 4. Контроль санкций КоАП и чистоты вывода (Anti-Regression Checks)
При проверке целевых URL и доменов убедись, что:
1. **Ненулевая вилка штрафов**: Поле `Total Fine Range` при наличии `RED` или `ORANGE` нарушений НЕ возвращает `0 - 0 RUB`. Выводится реальная денежная вилка статьи КоАП РФ (для ИП или с учетом 50% скидки МСП по ст. 4.1.2) с примечанием: `(1-й контакт МСП: предупреждение по ст. 4.1.1 КоАП; штраф при жалобе / неисполнении предписания)`.
2. **Отсутствие сырых enum-кодов**: В выводе отсутствуют непереведенные строки вроде `custom-checkbox-or-consent-notice`, они отображаются на понятном русском языке.
3. **Отсутствие ложноположительных срабатываний по политике**: Если страница политики существует и доступна по коду 200, нарушение `missing-privacy-policy-link` не генерируется.
4. **Сквозная дедупликация**: Однородные элементы футера/шапки не дублируются построчно на каждую страницу, а объединяются в одну запись.
